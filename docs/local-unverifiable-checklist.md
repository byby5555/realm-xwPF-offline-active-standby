# 本机不可验项清单（开发机 → 真机）

> 适用范围：`realm-xwPF-offline-active-standby` 的开发机（Windows + Git Bash + Python 3.11）。
> 真机：Linux VPS（生产环境是 Linux，行为与开发机在若干点上是**不一样**的）。
>
> 这份清单的用法：**每条都写清楚「本机为什么验不了」「真机怎么验」「验收判据是什么」**，
> 不写「本机无法验证」这种含糊话 —— 含糊的条目会在真机验收时被跳过，或者被临时改口径。

## 新增条目时的格式（仍然有效）

| 字段 | 要求 |
|------|------|
| 本机不可验项 | 具体到「哪个行为 / 哪个判定分支」 |
| 为什么本机不可验 | 说清机制差异（内核语义 / 文件系统 / 权限模型 / 环境），不是「跑不了」 |
| 真机验法 + 验收判据 | 给可执行的命令 + 可判定的结果（不是「看看对不对」） |

> ⚠️ **同名异义提醒**（本项目最大的误伤源，删功能前逐条核对）：
> 「主备」= **权重主备**（保留）vs **主备池**（已删除）；
> 「legacy」= **剔除模式**（保留）vs **realm 回环旧模式**（已删除）vs
> 测试用例 `04_legacy_merged.sh` 里那层「并入的旧脚本」。
